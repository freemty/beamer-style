# Beamer Style

5 low-saturation color themes for academic Beamer slides — unified visual identity across presentations.

Sister skill of [paper-style](https://github.com/freemty/paper-style) — same color palette, different medium.

## Themes

red / blue / gold / green / purple — each with 4 layout variants.

## Usage

```
/beamer-style init --theme blue       # scaffold slides project
/beamer-style guard                   # detect theme, assist with slides
```

## Install

```bash
ln -sf $(pwd) ~/.claude/skills/beamer-style
```
